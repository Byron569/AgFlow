## 接口文档生成（只读）

扫描现有代码，产出一份可直接给人看的 API 文档，不修改任何文件。

步骤：
1. **找路由面** —— 按框架惯例定位端点声明（如 Express/Koa 的 `router.*`、FastAPI 的
   `@app.`、Spring 的 `@RequestMapping`、Go 的 `http.Handle*`），先列清单再逐项展开。
2. **逐端点提取** —— 方法、路径（含路径参数）、鉴权要求、查询/体参数（名字、类型、是否必填）、
   响应结构、可能的错误码。参数与响应尽量从类型定义或校验逻辑里取，不靠猜。
3. **输出**（直接在回答里，Markdown）：

   ## API 文档 —— <服务名>

   ### 约定
   - 基地址：<从配置/路由前缀取>
   - 鉴权：<方式；取不到就写「待确认」>

   ### <METHOD> <path>
   - 参数：<表格式列表：名称 / 位置 / 类型 / 必填 / 说明>
   - 请求示例：<curl 或 JSON>
   - 响应示例：<JSON>
   - 错误：<码 + 含义>

4. 纪律：任何取不到的字段标「待确认」，绝不编造；私有/内部端点也如实标注。
   文档输出完即止，不要顺手改任何文件。
