## 抓取并总结

给定一个 URL，抓取它的内容并返回简明的 Markdown 摘要。

步骤：
1. 用 `WebFetch` 抓取页面（也可以用 `Bash` 执行 `curl -sL <url> | head -200` 作为兜底）。
2. 提取正文——忽略导航、页脚、广告和模板内容。
3. 返回结构化摘要，包含：
   - **标题**（页面的 `<title>` 或主标题）
   - **一段话概述**：这个页面讲的是什么
   - **要点**：列表（最多 5 条）
   - **来源**：抓取的 URL

不要把抓取到的内容保存或写到任何地方。直接返回摘要。
