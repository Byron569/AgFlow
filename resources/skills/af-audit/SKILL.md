## 代码审计（只读）

做一次只读的代码质量扫描，返回发现报告。不要修改任何文件。

步骤：
1. **划定范围** —— 判断主要语言与入口（`package.json`、`Cargo.toml`、`go.mod`、`pyproject.toml` 等）。
2. **扫描** —— 用 `Grep` 和 `Read` 查找：
   - 未处理的 Promise 拒绝 / 被忽略的错误
   - 硬编码的密钥或凭据（key、token、密码）
   - 标记已知债务的 `TODO`/`FIXME`/`HACK` 注释
   - 死导出（有导出符号，但仓库内无人 import）
   - 明显的类型安全缺口（未检查的 `any`、缺失的空值保护）
3. **报告** —— 按严重程度排序输出发现列表（Critical → High → Medium → Low）：
   ```
   ## 审计报告 —— <项目名>

   ### Critical
   - [文件:行号] <描述>

   ### High
   - ...

   ### 小结
   共扫描 <文件数> 个文件，发现 <总数> 处问题。
   ```
4. 报告完即止。不要顺手修任何东西。
